# Лабораторна робота №6: C++ openCV

**Виконала:** Любочка Вікторія, група ФБ-44

## Опис проекту
Інтерактивний додаток на C++ з використанням бібліотеки OpenCV для захоплення,
обробки та фільтрації відеопотоку з веб-камери в реальному часі.

## Функціонал
* **Фільтри реального часу**: Швидке перемикання між режимами Normal (Без ефектів),  Glitch (Ефект зсуву каналів та цифрових завад) та Pixelate (Ретро-пікселізація).
* **Інтерактивне малювання**: Можливість малювати власні лінії мишкою поверх відеопотоку у спеціальному режимі.
* **Регулювання яскравості**: Зручний графічний повзунок (Trackbar) для миттєвої зміни яскравості та контрасту картинки.
* **Екранне табло (HUD)**: Напівпрозорий графічний інтерфейс  користувача, що відображає поточний режим та підказки щодо гарячих клавіш.

### Операційна система
* **ОС**:  Linux

### Вимоги до заліза
* **Процесор**: Будь-який Intel/AMD x86_64 процесор (багатопотоковість прискорить компиляцію).
* **Оперативна пам'ять**: Мінімум 2 ГБ ОЗУ.
* **Камера**: Будь-яка стандартна USB Веб-камера (UVC-сумісна), що підтримує базову роздільну здатність **VGA (640x480)**.

### Програмні залежності
Проєкт використовує такі системні пакети та бібліотеки (встановлюються автоматично через скрипт ініціалізації):
* `g++` / `build-essential` (з підтримкою стандарту C++17)
* `CMake` (версії 3.10 або новішої)
* `OpenCV` (модулі core, videoio, highgui та imgproc)
* `v4l-utils` (відеодрайвери Video4Linux для коректної роботи з USB-пристроями)
* `libgtk-3-dev` / `GStreamer` (для рендерингу графічних вікон OpenCV)

## Інструкція зі збірки та запуску

Щоб розгорнути та запустити проєкт на Ubuntu, відкрийте термінал у папці з програмою та виконайте чотири прості кроки:

### Крок 1: Надання прав на запуск скриптів
Дозвольте операційній системі запускати автоматизаційні Bash-скрипти:
```chmod +x preinstall.sh build.sh run.sh```

### Крок 2: Встановлення залежностей
Запустіть скрипт для автоматичного оновлення пакетів та встановлення компілятора з бібліотекою OpenCV:
```./preinstall.sh```

### Крок 3: Компіляція проєкту
Запустіть збірку проєкту. Скрипт автоматично створить ізольовану папку build/, запустить CMake та скомпілює код,
використовуючи всі доступні ядра вашого процесора:
```./build.sh```

### Крок 4: Запуск програми
Запустіть додаток. За замовчуванням програма намагатиметься підключитися до першої камери у системі (/dev/video0):
```./run.sh```

## Керування
Керування додатком здійснюється за допомогою клавіатури та миші, коли графічне вікно "Camera Vision" є активним:
* 0 - Увімкнути звичайний режим без фільтрів (Normal)
* 1 - Увімкнути режим цифрових завад (Glitch)
* 2 - Увімкнути ретро-ефект пікселів (Pixelate)
* D / d - Увімкнути режим малювання. Затисніть ЛКМ та тягніть мишу для створення ліній.
* Tab - Гортати режими обробки
* X / x - Повністю очистити екран від усіх намальованих ліній
* Повзунок - Регулювання рівня Яскравості відеопотоку (від 0 до 100)
* Q / Esc - Вийти з програми та закрити камеру

## Структура репозиторію

* rc/ — Файли реалізації коду C++ (main.cpp, CameraProvider.cpp, FrameProcessor.cpp, KeyProcessor.cpp, Display.cpp).

* include/ — Заголовочні файли опису класів (CameraProvider.hpp, FrameProcessor.hpp, KeyProcessor.hpp, Display.hpp).

* CMakeLists.txt — Головний конфігураційний файл для системи збірки CMake.

* preinstall.sh / build.sh / run.sh — Автоматизаційні скрипти життєвого циклу програми.

* .gitignore — Правила виключення тимчасового сміття компілятора та кешу IDE з репозиторію Git.

## Опис проекту
Головна ідея проєкту — поєднання класичних алгоритмів комп'ютерного зору
та сучасних методів глибокого машинного навчання із концепціями багатопотоковості.
Додаток не просто накладає візуальні ефекти, а демонструє практичне вирішення поширеної
інженерної проблеми: як інтегрувати важкі ШІ-обчислення у графічні додатки,
зберігаючи інтерфейс користувача плавним, чутливим та ізольованим від затримок інференсу.

## Програмні залежності

Проєкт побудовано на базі сучасного стеку технологій для Linux-систем. Усі перелічені компоненти та бібліотеки встановлюються повністю автоматично під час запуску скрипта ініціалізації (`./preinstall.sh`):

* **`g++` / `build-essential`** — базовий інструментарій компілятора GCC із повною підтримкою стандарту **C++17**.
* **`CMake`** (версії 3.10 або новішої) — кросплатформена система автоматизації збірки та генерації конфігураційних файлів проєкту.
* **`OpenCV`** — основна графічна бібліотека комп'ютерного зору. Проєкт активно використовує її ключові модулі: `core`, `videoio`, `highgui` та `imgproc`.
* **`v4l-utils`** — набір відеодрайверів та системних утиліт *Video4Linux* для стабільної низькорівневої взаємодії ОС із USB-веб-камерами.
* **`libgtk-3-dev` / `GStreamer`** — підсистеми рендерингу графічного інтерфейсу, необхідні для коректної роботи віконного режиму OpenCV HighGUI в оточеннях Linux (GNOME/X11/Wayland).

##  Логіка взаємодії потоків

Проєкт чітко розмежовує обов'язки між двома паралельними потоками через безпечний
шлюз обміну даними (клас `FaceDetector`):

### 1. Main Thread (Головний UI-потік)
* **Цикл:** Працює на максимально можливій швидкості процесора/камери.
* **Дії:**
  1. Зчитує новий сирий кадр із веб-камери.
  2. Застосовує базові фільтри та відправляє **копію кадру** в `FaceDetector`.
  3. Не чекаючи відповіді від ШІ, миттєво забирає з `FaceDetector` **останні відомі координати** облич.
  4. Малює ці координати на поточному кадрі.
  5. Миттєво відображає картинку на екрані (`cv::imshow`).
* **Результат:** Відео не гальмує, інтерфейс реагує миттєво. Рамка може зовсім трохи відставати від різких рухів, але загальний FPS залишається максимально високим.

### 2. Worker Thread 
* **Цикл:** Працює асинхронно у нескінченному фоновому режимі.
* **Дії:**
  1. Переходить у режим очікування за допомогою `std::condition_variable`, не навантажуючи процесор.
  2. Як тільки надходить сигнал про новий кадр від UI-потоку — прокидається й забирає кадр у локальну матрицю.
  3. Запускає важку математику інференсу: `net.forward()`.
  4. Обчислює координати прямокутників та оновлює спільну змінну результатів.
  5. Повторює цикл наново.

## Інструкція зі збірки та запуску

Щоб розгорнути та запустити проєкт на Ubuntu, відкрийте термінал у папці з програмою та виконайте чотири прості кроки:

### Крок 1: Надання прав на запуск скриптів
Дозвольте операційній системі запускати автоматизаційні Bash-скрипти:
```chmod +x preinstall.sh build.sh run.sh```

### Крок 2: Встановлення залежностей
Запустіть скрипт для автоматичного оновлення пакетів та встановлення компілятора з бібліотекою OpenCV:
```./preinstall.sh```

### Крок 3: Компіляція проєкту
Запустіть збірку проєкту. Скрипт автоматично створить ізольовану папку build/, запустить CMake та скомпілює код,
використовуючи всі доступні ядра вашого процесора:
```./build.sh```

### Крок 4: Запуск програми
Запустіть додаток. За замовчуванням програма намагатиметься підключитися до першої камери у системі (/dev/video0):
```./run.sh```

## Керування
Керування додатком здійснюється за допомогою клавіатури та миші, коли графічне вікно "Camera Vision" є активним:
* 0 - Увімкнути звичайний режим без фільтрів (Normal)
* 1 - Увімкнути режим цифрових завад (Glitch)
* 2 - Увімкнути ретро-ефект пікселів (Pixelate)
* F / f — Режим Face Detection
* D / d - Увімкнути режим малювання. Затисніть ЛКМ та тягніть мишу для створення ліній.
* Tab - Гортати режими обробки
* X / x - Повністю очистити екран від усіх намальованих ліній
* Повзунок - Регулювання рівня Яскравості відеопотоку (від 0 до 100)
* Q / Esc - Вийти з програми та закрити камеру

├── CMakeLists.txt              # Головний конфігураційний файл системи збірки CMake
├── .gitignore                  # Файл виключень Git
├── README.md                   # Повна документація проєкту (цей файл)
├── preinstall.sh               # Скрипт інсталяції системних залежностей
├── build.sh                    # Скрипт автоматичної багатопоточної компіляції проєкту
├── run.sh                      # Скрипт перевірки, автозавантаження моделей ШІ та запуску додатка
│
├── include/                    # Директорія заголовочних файлів (.hpp)
│   ├── AppState.hpp            # Опис структури єдиного стану програми
│   ├── CameraProvider.hpp      # Інтерфейс модуля захоплення відеопотоку
│   ├── Display.hpp             # Інтерфейс модуля створення вікон та повзунків 
│   ├── FaceDetector.hpp        # Декларація асинхронного фонового потоку ШІ та примітивів синхронізації
│   ├── FrameProcessor.hpp      # Інтерфейс головного обчислювального конвеєра ефектів
│   └── KeyProcessor.hpp        # Інтерфейс обробника подій введення користувача
│
└── src/                        # Директорія файлів реалізації (.cpp)
    ├── main.cpp                # Головний UI-потік, ініціалізація та цикл очікування кадрів
    ├── CameraProvider.cpp      # Реалізація низькорівневого підключення до веб-камери
    ├── Display.cpp             # Логіка рендерингу фінальної матриці кадру на екран
    ├── FaceDetector.cpp        # Паралельний робочий потік та інференс нейромережі Caffe
    ├── FrameProcessor.cpp      # Реалізація ефектів, ліній малювання та HUD-табло
    └── KeyProcessor.cpp        # Логіка трансляції ASCII-кодів у команди керування додатком

# Лабораторна робота №5: Наука про дані: обмін результатами та початковий аналіз

**Виконала:** Любочка Вікторія, група ФБ-44

## Опис проекту
Метою роботи є розробка інтерактивного веб-додатка на базі бібліотеки Streamlit для візуалізації та аналізу індексів стану вегетації (VHI, TCI, VCI) в Україні. Програма дозволяє:
* Обирати часовий ряд (VHI, TCI, VCI) для аналізу.
* Фільтрувати дані за конкретною областю, інтервалом тижнів та років.
* Сортувати відфільтровані дані за зростанням або спаданням показника.
* Переглядати дані у трьох форматах: таблиця, лінійний графік динаміки та порівняльна стовпчикова діаграма середніх значень по регіонах.

## Процес реалізації
Для створення даного аналітичного інструменту було виконано наступні кроки:
* Збір та підготовка даних: реалізовано автоматичне завантаження актуальних CSV-файлів із серверів NOAA за допомогою бібліотеки urllib.
* Очищення та трансформація: за допомогою бібліотеки Pandas виконано видалення технічних HTML-тегів, обробку пропущених значень та конвертацію типів даних для забезпечення точності аналізу.
* Нормалізація ідентифікаторів: розроблено механізм перетворення внутрішніх ідентифікаторів NOAA до стандартного переліку областей України за допомогою словника відповідності.
* Розробка інтерфейсу: побудовано багатовкладковий інтерфейс з використанням Streamlit, де реалізовано кешування даних для оптимізації швидкодії та систему управління станом сесії для коректного скидання налаштувань фільтрації.
* Візуалізація: інтегровано динамічні графіки та діаграми, що автоматично оновлюються при зміні параметрів вхідних даних.

## Вимоги до системи

* Інтерпретатор: `Python 3.9` або вище.
* Операційна система: Windows (рекомендовано), Linux або macOS.
* Основні бібліотеки: `Pandas`, `Streamlit`.

## Налаштування та встановлення
1. Клонування репозиторію або підготовка папки
Переконайтеся, що файл lab5.py та requirements.txt знаходяться в одній директорії.

2. Створення віртуального середовища 
Для ізоляції залежностей проєкту створіть віртуальне середовище:
`python -m venv venv`
Активація для Windows: `venv\Scripts\activate`

3. Встановлення залежностей
Встановіть необхідні пакети за допомогою менеджера пакетів pip:
`pip install -r requirements.txt`

## Iнструкція для запуску
Щоб запустити веб-додаток, виконайте команду в терміналі (перебуваючи в папці проєкту):
`python -m streamlit run lab5.py`
Після виконання команди у вашому браузері за замовчуванням відкриється нова вкладка з інтерфейсом дашборду
